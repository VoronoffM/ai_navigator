# 🤖 AI-Штурман (AI-Navigator)

Гибридный торговый робот-ассистент для T-Invest API (песочница Sandbox).

## 🌟 Особенности
- **Квантовая математика**: Поиск аномалий перепроданности/перекупленности на основе Z-Score и линий Боллинджера.
- **Торговый терминал**: Интерактивный график Plotly со свечами, сигналами BUY/SELL и ведением логов операций.
- **Роботизированная торговля**: Автоматическое выставление рыночных ордеров при срабатывании сигналов (с проверкой текущего портфеля).
- **NLP-фильтр**: Отсеивание ложных сигналов на основе новостного фона (текущая версия — умная эвристика, в планах — GraphRAG/LLM).
- **Интеграция с Telegram**: Мгновенные алерты о совершенных сделках.

## 🚀 Инструкция по развертыванию (MacOS / Windows)

### 1. Установка Python и Git
- **Windows**: Скачайте Python 3.11+ с [python.org](https://www.python.org/downloads/). ⚠️ **ВАЖНО:** При установке поставьте галочку **"Add Python to PATH"**. Установите [Git for Windows](https://git-scm.com/download/win).
- **MacOS**: Python можно установить через Homebrew (`brew install python`) или скачать с официального сайта. Git обычно уже предустановлен.
