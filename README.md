# 🤖 AI-Штурман (AI-Navigator)

Гибридный мульти-агентный торговый помощник для T-Invest API (Песочница Sandbox).
Проект разработан для хакатона Т-Банка «Инвест. Премаркет» (трек AI + Инвестиции).

## 🌟 Ключевые особенности
- **Мульти-Агентная архитектура**: 7 независимых модулей (Market, Quant, NLP, Risk, Execution, Orchestrator, QA).
- **Гибридный AI (Локальный)**: Использует жесткие риск-правила (Hard Rules), векторный поиск (RAG на ChromaDB) и локальную LLM (Qwen 2.5 через Ollama + Outlines для строгого JSON).
- **Динамический риск-менеджмент**: Автоматически запрашивает размер лота и торговый статус из API (защита от ошибки 30079).
- **Торговый терминал**: Интерактивный график Plotly, сканер рынка и ручное управление.
- **Интеграция с Telegram**: Мгновенные алерты о сделках с указанием количества лотов и итоговой суммы.

## 🚀 Инструкция по развертыванию (MacOS / Windows)

### 1. Требования к окружению
* Python 3.11+
* Установленный [Ollama](https://ollama.com/) для работы локального AI.

### 2. Установка AI-моделей
Выполните в терминале:
```bash
ollama pull qwen2.5:3b
ollama pull nomic-embed-text
