# 🤖 AI-Штурман (AI-Navigator)

Аналитический AI Co-pilot для инвестора, интегрированный с T-Invest API (Песочница Sandbox).
Проект разработан для хакатона Т-Банка «Инвест. Премаркет» (трек AI + Инвестиции).

## 🌟 Ключевые особенности
- **Мульти-Агентная архитектура**: 7 независимых модулей (Market, Quant, NLP, Risk, Execution, Orchestrator, QA).
- **Explainable AI (Объяснимый ИИ)**: Нейросеть не просто дает сигнал, а формирует структурированный отчет: Факты, Возможные объяснения, Что не подтверждено, Источники.
- **Citation-Aware RAG**: Векторный поиск (ChromaDB) возвращает факты с указанием источника и даты (Интерфакс, РБК и т.д.).
- **Observability (Reasoning Trace)**: Скрытый лог, в котором нейросеть объясняет *почему* она приняла то или иное решение.
- **Fail-Closed безопасность**: Если локальная LLM (Ollama) отключается или выдает ошибку, система блокирует новые входы (не торгует вслепую).
- **Динамический риск-менеджмент**: Автоматический запрос размера лота и торгового статуса из API Т-Инвестиций (защита от ошибки 30079).

## 🛠 Технологический стек
* **UI:** Streamlit, Plotly
* **Backend:** Python 3.11, Pandas, Numpy
* **AI & RAG:** Ollama (Qwen 2.5:3b), Outlines, LangChain (langchain-chroma)
* **API:** T-Tech Investments SDK (gRPC)
* **Уведомления:** Telegram Bot API

## 🚀 Инструкция по развертыванию (MacOS / Windows)

### 1. Требования к окружению
* Python 3.11+
* Установленный [Ollama](https://ollama.com/) для работы локального AI.
* (Опционально) Docker, если Ollama не запускается на вашей версии macOS.

### 2. Установка AI-моделей
Выполните в терминале для загрузки моделей (Qwen для анализа, Nomic для эмбеддингов):
```bash
ollama pull qwen2.5:3b
ollama pull nomic-embed-text
