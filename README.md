# AI Штурман

MVP для хакатона «Инвест. Премаркет». Терминал показывает последние цены и свечи GAZP, SBER, LKOH, ROSN, VTBR и BELU из песочницы Т‑Инвестиций. В правой панели можно выбрать исторический эпизод или симуляцию и получить серверный разбор сигнала. Правила срабатывания настраиваются отдельно в Agent Studio.

## Запуск на macOS

Для новой установки нужны Python 3.11 или новее и Node.js 22.12 или новее. Если у вас установлен Homebrew, инструменты можно поставить командой `brew install python@3.13 node`. В командах ниже `python3.13` можно заменить на ваш совместимый интерпретатор.

Из корня репозитория в ветке `mvp-rebuild` выполните команды установки.

```bash
python3.13 -m venv .venv-mvp
source .venv-mvp/bin/activate
python -m pip install -r backend/requirements.txt
npm --prefix frontend ci
npm --prefix frontend run build
```

### Переменные окружения

| Имя | Назначение |
| --- | --- |
| `TBANK_TOKEN` | Токен T‑Invest API с доступом к рыночным данным в песочнице. Сервер берёт его из окружения или из файла `.env` в корне репозитория. Переменная окружения имеет приоритет. |
| `OLLAMA_URL` | Адрес Ollama. По умолчанию `http://127.0.0.1:11434`. |
| `OLLAMA_API_KEY` | Ключ для удалённой Ollama. Для локальной Ollama ключ не требуется. |
| `ANALYSIS_MODELS` | Список доступных в Agent Studio моделей через запятую. По умолчанию `qwen2.5:3b`. Установите выбранные модели в Ollama. |
| `ANALYSIS_DEFAULT_MODEL` | Модель по умолчанию из `ANALYSIS_MODELS`. Если переменная пропущена, сервер берёт первую модель списка. |
| `SSL_CERT_FILE` | Необязательный путь к PEM-файлу доверенных сертификатов для процесса сервера. Нужен, если Python не доверяет сертификату песочницы. |

При отсутствии токена терминал показывает причину недоступности рыночных данных и позволяет пройти демонстрацию. После изменения переменных окружения перезапустите FastAPI.

Для локального ИИ-разбора установите [Ollama](https://ollama.com/download), запустите приложение Ollama или выполните `ollama serve`. В другом окне загрузите модель.

```bash
ollama pull qwen2.5:3b
```

Затем запустите FastAPI одним процессом. Разборы хранятся в его памяти.

```bash
source .venv-mvp/bin/activate
python -m uvicorn backend.main:app --host 127.0.0.1 --port 8000
```

Откройте [терминал](http://127.0.0.1:8000). Для разработки интерфейса можно оставить FastAPI запущенным и во втором окне выполнить `npm --prefix frontend run dev`, затем открыть [сервер разработки](http://localhost:5173).

### Если песочница недоступна

Если терминал сообщает об ошибке сертификата песочницы, добавьте в `.env` путь к PEM-файлу со стандартными доверенными сертификатами и корневым сертификатом НУЦ Минцифры. Затем перезапустите FastAPI. [Инструкция Т‑Инвестиций по сертификатам](https://developer.tbank.ru/invest/intro/developer/network).

```dotenv
SSL_CERT_FILE="/полный/путь/к/tbank-trusted-ca.pem"
```

Если соединение прерывается при включённом VPN, добавьте `sandbox-invest-public-api.tbank.ru` в список прямого подключения (`DirectSites`) в активном профиле INCY и переподключите VPN. [Документация INCY](https://github.com/INCY-DEV/incy-docs/blob/main/ru/dev-docs/routing.md).

## Рыночные данные

- `ShareBy` запрашивает сведения об акциях класса `TQBR`. `GetLastPrices` получает цены последних сделок. `GetCandles` получает часовые свечи за 14 дней или дневные за 180 дней. Все три метода вызываются через [REST песочницы Т‑Инвестиций](https://developer.tbank.ru/invest/intro/developer/protocols/).
- Терминал запрашивает новые данные примерно раз в минуту. Для ручного запроса используйте кнопку обновления в шапке. Время сделки и последней свечи отображается по Москве.

## Историческое воспроизведение

В правой панели выберите **«Эпизод для воспроизведения»** и нажмите **«Воспроизвести эпизод»**. При смене эпизода текущий просмотр и карточка разбора сбрасываются; настройки Agent Studio сохраняются. Доступны пауза, переход к следующей свече, скорость 1×/2×/4× и повтор.

| Эпизод | Данные | Особенность |
| --- | --- | --- |
| Падение без дивидендов · GAZP, 22 мая 2025 | Сохранённые свечи T-Invest MCP | Рекомендация не выплачивать дивиденды; прежний эпизод сохранён. |
| Рост на дивидендах · VTBR, 28 апреля 2025 | Часовые свечи Московской биржи ISS | Рост на дивидендном раскрытии в 13:39. |
| Падение на слухах о банкротстве · SPBE, 27 ноября 2023 | Часовые свечи Московской биржи ISS | Сообщение о заявлении в суд и опровержение компании. |

В **Agent Studio** выберите нужный актив (GAZP, VTBR или SPBE), период **1ч**, направление и порог, включите правило и назначьте агента. Выбор эпизода не создаёт и не меняет правила. Если правила не подходят или порог не достигнут, воспроизведение завершается без сигнала. Для проверки всех публичных эпизодов можно настроить одно правило на эти три актива: **«Изменение цены по фиксированному порогу» → «Рост или падение» → 2% → 1ч**, с действием T-Invest MCP и включённой проверкой новостей. Для GAZP также работает исходное правило аномального падения цены. Ранее сохранённые правила с DEMO при загрузке переключаются на SPBE, остальные настройки сохраняются.

BELU сохранён как внутренний проверочный кейс и не показывается в выборе эпизодов. Для его первого разрыва используется фиксированный процентный порог: часовые Z-оценки для перехода между сессиями не рассчитываются. В свечах BELU исключён час 09:00 с аукционными значениями; предыдущая сохранённая свеча — 15 августа, 23:00, с закрытием 4680 ₽, первая новая — 22 августа, 10:00, с закрытием 781 ₽. Полученное изменение −83,31% относится к этим двум свечам, а не к стоимости портфеля. Корпоративный контекст: [сообщение 4 июля о распределении семи новых акций на одну прежнюю](https://www.interfax.ru/business/969335), [возобновление торгов 22 августа](https://www.interfax.ru/business/977582). Ограничения ликвидности описаны в [FAQ эмитента](https://novabev.com/investors/shareholder-center/stock-split-faqs/); точное время публикации FAQ не установлено, поэтому его текст не подставляется в исторический вход модели.

VTBR: раскрытие [решения набсовета 28 апреля в 13:39](https://www.e-disclosure.ru/portal/event.aspx?EventId=9E-C05nxQ30WwcB6uIFpXFQ-B-B) доступно к сигналу в 14:00. Цена закрытия меняется с 86,65 ₽ до 107,14 ₽ (+23,65%). Это часовая динамика, а не итог торгового дня. GAZP: [публикация Интерфакса в 15:46](https://www.interfax.ru/business/1027187), сигнал в 16:00, изменение с 134,23 ₽ до 131,35 ₽ (−2,15%).

Материалы и завершённые свечи поступают в разбор только к соответствующему историческому времени. Известное ранее действующее корпоративное событие может оставаться контекстом. Новые исторические пакеты используют выбранные сохранённые публикации, а не полную новостную ленту; отсутствие материала не доказывает отсутствие причины. Произвольные источники и календарь ЦБ для новых эпизодов доступны только при наличии сохранённой версии; иначе проверка отмечается как недоступная. Идентификатор эпизода и версия данных разделяют кеши разборов.

SPBE: [заголовок «Коммерсанта» в 10:13](https://www.kommersant.ru/doc/6364432) и [опровержение Интерфакса в 10:38](https://www.interfax.ru/business/933355) доступны к закрытию свечи в 11:00. Из обновлявшейся статьи «Коммерсанта» используется только заголовок, без более поздних дополнений. Первая свеча 27 ноября: открытие 95,9 ₽, максимум 96 ₽, минимум 63,8 ₽, закрытие 90 ₽; предыдущее закрытие 24 ноября в 23:00 — 98 ₽. Изменение между этими закрытиями −8,16%, а не внутридневное падение на 35%. Аукционный час 09:00 исключён. Для первого разрыва между сессиями нужны фиксированный процентный порог или другой подходящий сценарий: часовая Z-оценка не рассчитывается. Все OHLCV и объёмы получены из ISS без интерполяции; адреса запросов и контрольные суммы сохранены в `backend/data/episodes/spbe.json`. Повторная загрузка: `python -m backend.import_spbe_episode`. Заключение ЦБ от февраля 2024 года не включено в исторический контекст. Итоговый разбор генерирует выбранная модель, готовый ответ не сохранён.

Публичный DEMO заменён на SPBE. Вымышленные варианты сохранены только для внутренних проверок пустой, старой и недоступной новостной ленты и не показываются в интерфейсе.

Для воспроизведения достаточно сохранённых данных, без доступа к бирже. Модель нужна для ИИ-разбора: при её недоступности остаются сигнал, расчёты и сводка по источникам с причиной сбоя. Цены, объёмы и происхождение новых исторических данных сохранены в `backend/data/episodes/`. Каталог и поток: `GET /api/replay/episodes`, `GET /api/replay/episodes/{id}`. Прежний `/api/replay/gazprom` сохранён для совместимости.

В **Agent Studio → Интеграции** выберите, где запускать модель.

- **Локально** — запустите Ollama и загрузите выбранную модель по инструкции в студии.
- **Облачный API** — укажите публичный HTTPS-адрес провайдера, идентификатор модели и API-ключ. Подойдёт базовый URL (например, `https://api.example.com/v1`) или полный URL, оканчивающийся на `/chat/completions`. Провайдер должен поддерживать совместимый Chat Completions API с Bearer-авторизацией. Сервер отправит материалы эпизода по указанному адресу. Адрес и модель сохраняются в браузере, ключ действует до перезагрузки страницы.

По умолчанию разбор включает новости, сравнение с индексом, дивиденды и отчётность. В симуляциях используется учебный индекс. Изменения подключения применятся при следующем воспроизведении. Повтор с теми же настройками использует текущий или готовый разбор. После ошибки разбор можно запустить снова.

Для воспроизведения достаточно сохранённых данных. Если модель недоступна, карточка покажет сигнал, доступные материалы, расчёты и причину сбоя ИИ-разбора. Модель вызывается и при пустой ленте, если есть успешно выполненные проверки: она получает сигнал, расчёты и статусы источников. Если проверенная новостная лента и остальные выполненные действия не дали убедительного объяснения, агент использует рабочую гипотезу «скорее всего, рыночный шум» с оговоркой о пределах проверенных источников. При недоступной или отключённой ленте и отсутствии изученного новостного источника одних цен недостаточно для такого вывода. Если нет ни материалов, ни успешно выполненных проверок, ИИ-разбор пропускается.

Серверный адаптер [T‑Invest MCP](https://developer.tbank.ru/invest/mcp) поддерживает четыре запроса на чтение для недавних событий. Исторический сценарий загружает сохранённые материалы и свечи, доступные к моменту сигнала.

Проверки серверного разбора можно запустить из корня репозитория.

```bash
python -m unittest discover -s backend/tests -v
```
