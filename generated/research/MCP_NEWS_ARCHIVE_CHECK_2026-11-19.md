# Проверка новостного архива T-Invest MCP

Проверено 19 ноября 2026 года, около 18:33 МСК. Реальные сетевые запросы с существующим токеном проекта; токен не записан в отчёт. Код работающего приложения не изменён.

## Результат

**В доступной выдаче MCP песочницы новости GAZP за 22 мая 2025 года не найдены.** Завершена пагинация как выдачи GAZP, так и общей ленты. Это не утверждение о недоступности публикации у Интерфакса или о глубине основного контура Т-Инвестиций.

Последовательность размеров страниц общей ленты: 1000, 1000, 1000, 1000, 188. Повторяющихся идентификаторов записей не обнаружено. Первая предварительная проверка немного раньше вернула 4186 записей; лента пополнялась между запусками. Для итогового отчёта использован последний полный обход.

Дополнительно проверены заголовки, краткие содержания и полные тексты общей выдачи на `2025-05-22`, `22.05.2025`, `22 мая 2025` и идентификатор сохранённой статьи `1027187`. Совпадений нет. Среди заголовков записей с упоминанием «Газпром» также нет дивидендной новости нашего эпизода. Полные тексты статей в отчёт не сохранялись.

## Что реально поддерживает инструмент

Сервер: `t-invest-mcp-server`, версия `1.53.0`. Каталог MCP сообщил 68 инструментов.

Схема `invest_get_news` содержит только:

- `instrumentId` — тикер, необязательный;
- `cursor` — курсор следующей страницы, необязательный;
- `limit` — размер страницы; в описании значение по умолчанию 1000.

Параметров начала/конца периода в полученной схеме нет. Прямого запроса «GAZP с 22 мая по 23 мая 2025 года» этот инструмент в опубликованной схеме не предоставляет. Для поиска глубже используется фактический `nextCursor` сервера, а не придуманный курсор или неподдерживаемый фильтр даты.

Поле `ts` в выходной схеме называется **временем обновления записи**, а не гарантированно временем первоначальной публикации статьи. Поэтому диапазон `ts` нельзя автоматически превращать в утверждение о первоначальных датах всех публикаций или сроке хранения архива.

## Проверка основного контура

На `https://invest-public-api.tbank.ru/mcp` сделаны две попытки соединения. Обе завершились `ConnectTimeout`, без ответа MCP и без результата авторизации. Поэтому:

- нельзя заключать, что основной контур имеет такой же архив;
- нельзя заключать, что токен принят или отклонён основным контуром;
- причина сетевой недоступности отдельно не установлена.

Песочница `https://sandbox-invest-public-api.tbank.ru/mcp` отвечала успешно.

## Что это означает для продукта

Сохранённая публикация Интерфакса для эпизода GAZP нужна не только для повторяемости: по проверенному сегодня пути MCP песочницы восстановить это историческое событие не удалось.

Корректное утверждение для показа: «Для истории используются сохранённые материалы. В проверенной выдаче MCP песочницы доступны только записи с сегодняшними метками обновления; публикация за 22 мая 2025 года не найдена».

Некорректное утверждение: «T-Invest MCP хранит новости только один день». Постоянный срок хранения не установлен. Чтобы его определить, нужны документация/ответ провайдера или повторные проверки в другие даты; для production — ещё и рабочее соединение.

В нашем адаптере приложения ограничение три страницы по 50 записей является отдельным локальным ограничением. В исследовании оно снято: выполнены реальные запросы по 1000 записей и завершена вся предоставленная сервером пагинация. Отсутствие исторической новости в этом исследовании не объясняется лимитом адаптера приложения.

## Материалы и повторение

- `mcp-news-discovery-sandbox.json` — фактическая схема инструмента.
- `mcp-news-scan-sandbox-GAZP.json` — результат по GAZP.
- `mcp-news-scan-sandbox-all.json` — диапазоны страниц и результат общей ленты.
- `mcp-news-discovery-production.json` — ошибка доступа к основному контуру.
- `mcp_news_probe.py`, `mcp_news_scan.py` — скрипты повторной проверки; токен читается из окружения/файла `.env` проекта и не выводится.

Из корня `ai_navigator`:

```bash
.venv-mvp/bin/python generated/research/mcp_news_probe.py sandbox
.venv-mvp/bin/python generated/research/mcp_news_scan.py sandbox GAZP 10 1000
.venv-mvp/bin/python generated/research/mcp_news_scan.py sandbox ALL 20 1000
```

Скрипты завершают обход при `hasNext=false`; бюджет страниц предотвращает неограниченный обход, если объём ленты изменится. Повторный запуск перезаписывает соответствующий JSON-отчёт и может показать другое количество новостей.
